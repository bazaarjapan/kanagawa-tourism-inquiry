# 神奈川県観光探究

神奈川県の観光をテーマにした探究レポートの作業記録と成果物をまとめるリポジトリです。

## 目的

- 神奈川県の観光について、問いを立て、資料を調べ、考察を深める
- 調査・判断・修正の過程を、あとから追える形で残す
- 最終的にWord形式のレポートとして提出できる状態にする

## フォルダ構成

- `research/`：問い、調査メモ、出典、仮説
- `report/`：レポートの原稿・完成版
- `process/`：ユーザーの指示、作業内容、判断理由の履歴
- `sources/`：利用した資料の一覧

## 進め方

1. 探究テーマと問いを具体化する
2. 調査計画と評価の観点を決める
3. 公的資料・一次資料を中心に調べる
4. 調査結果と考察を整理する
5. Wordレポートにまとめ、内容・出典・体裁を確認する

## 記録の方針

作業の節目ごとに、指示・実施内容・生成物・判断理由を `process/` に記録し、Gitコミットにも短い要約を残します。個人情報や未公開の認証情報は記録しません。

## 探究者本人の思考の記録

作業結果だけでなく、探究者本人がどこで自主的な考えを出したか、何を思い出したか、どんな気づきがあったか、何に迷ったかも記録します。本人の発言と、こちらが整理・提案した内容を分けて残し、探究の問いがどう生まれたかを追えるようにします。
